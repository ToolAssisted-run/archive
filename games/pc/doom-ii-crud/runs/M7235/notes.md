"Create Read Update Delete" - that's which words I assumed while reading this abbreviation. Actually, it doesn't mean anything. The wad was originally called CRUX (like "crooks"), but it was renamed to CRUD to avoid the naming overlap with some old obscure wad called "crux.wad".

CRUD is a custom short Doom wad, which consists of 4 playable maps. Map 5 loads the standard Doom 2 map. 
It can be downloaded from [https://www.doomworld.com/idgames/levels/doom2/a-c/crud|idgames] or [https://dsdarchive.com/wads/crud|dsdarchive].
Also, feel free to read the official release [https://www.doomworld.com/forum/topic/119791-crud-4-level-doom-ii-episode/|thread] on DoomWorld.%%%

!! Game objectives

* Emulator used: XDRE 2.20 (based on PrBoom+ 2.5.1.4)
* Doom goal: UV-Speed (complete each map as fast as possible on Ultra-Violence difficulty)
* Contains speed/entertainment tradeoffs
* Takes damage to save time
* Aims on in-game time instead of real time
* Heavy luck manipulation

!! Comments

! Demo playback
* Make a shortcut of dsda-doom.exe or prboom-plus.exe
* Open the Properties of the shortcut
* Insert commands at the end of its Target field, so it would look similar to that:
> D:\dsda-doom-0.25.3\dsda-doom.exe -iwad doom2.wad -file crud.wad -playdemo crud_allx133.lmp

! General comments

I spotted this mini-wad when it came out in February 2021. What caught my attention is that it was short (only 4 maps) and it was made by Moustachio who makes really relaxing and well-balanced maps.
Didn't have enough time to beat the WAD when the attention to it was at maximum. In case of hype, TASes usually come late when nobody expects it.

! Tricks and glitches

Check the game resources of [/GameResources/DoomEngine/Doom|Doom] for more info. This TAS uses linedef skipping, wallrunning and rocket jumping.

!! Stage by stage comments

! Map 1: At Doom's Yett

Pretty short map. Yellow skullkey was not that trivial because any shot would wake up a demo that immediately teleports in and blocks the path to the key. Fortunately, the guard gave the way for me to run through.

Picked up a secret rocket launcher to be used for a shortcut on Map 3. If I didn't run for it and just waited for the bridge to raise up, I would have saved about 1,5 secs.

! Map 2: Dungeon Crawl

It was really lucky there. There are a lot of monsters which can easily block your path. Killing a chaingunner and a spectre in a single SSG shot was complicated. What took the most time is the manipulation of my actions so arachnotrons near the yellow key didn't attack me and let run though, because it was important to have enough health for Map 3.

! Map 3: Castle Halls

So, I finally did that rocket jump and saved about 8 secs from the bridge that's supposed to be raised up. It wasn't that hard.

! Map 4: Residentail Zone

Key collection was a little tiring, but the luck was still on my side and monsters didn't try hard to stop me. Even though the run was smooth on turns, I had to shoot the arch-vile behind me, so I would have enough time to run away. Arch-viles in the exit room didn't spot me on time, so I had to pick up the regular route. I don't think I would have saved any time if any of them would start performing the attack as soon as I enter the room.
