!! Introduction

See [10404S] for general game details.

This movie attacks the game's fifth chapter: Vice City: Bent Cop Blues. This chapter features lots of driving around and an insufferable corrupt cop that blackmails you to work for him.

To reach this chapter without needing to run the previous chapter's movie as verification movie, I use the 'itsgallus' [https://m.thegtaplace.com/topdown/gta1/pc-cheats/|cheat code], whose only effect is to unlock all chapters. Then I change the name to 'eien86'.

The goal of this movie is to achieve 100%, as specified in the [https://www.speedrun.com/gta1?h=100&x=l9kvmokg|RTA rules]. That involves: finishing all 18 missions, getting all 12 secrets, and exiting the city. The secrets are achieved by picking up "Kill Frenzy" boxes, which don't need to be completed to count. It is not possible for it to report 16/16 at the end, since the second set of phones override the values of the first ones, due to a programming error in the game code.

I based my route on [https://www.speedrun.com/users/Tarakan3000|Tarakan3000]'s [https://www.speedrun.com/gta1/runs/y6650e6y|RTA WR] of the same category. I was able to follow his route pretty much without changes.
