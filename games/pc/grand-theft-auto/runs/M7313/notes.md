!! Introduction

See [10404S] for general game details.

This movie attacks the game's second chapter: Liberty City II: Heist Almighty. To reach it without needing to run the previous chapter's movie as verification movie, I use the 'itsgallus' [https://m.thegtaplace.com/topdown/gta1/pc-cheats/|cheat code], whose only effect is to unlock all chapters. Then I change the name to 'eien86'.

The goal of this movie is to achieve 100%, as specified in the [https://www.speedrun.com/gta1?h=100&x=l9kvmokg|RTA rules]. That involves: finishing all 13 missions, getting all 7 secrets, and exiting the city. The secrets are achieved by picking up "Kill Frenzy" boxes, which don't need to be completed to count.

I based my route on [https://www.speedrun.com/users/Tarakan3000|Tarakan3000]'s [https://www.speedrun.com/gta1/runs/ylke122z|RTA WR] of the same category. In this case too, I had to alter the order of missions due to the train's frame rule.
