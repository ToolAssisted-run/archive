🔺🟢🟦 (also written as /\ O [ ] or TCQ) is a platformer based on the art style of Piet Mondrian.

!! Game objectives

* Emulator used: BizHawk 2.11
* Model used: +2A
* Aims to complete the game as quickly as possible.

!! Comments

This is a tool-assisted speedrun of 🔺🟢🟦 for the ZX Spectrum. It completes the any% category, completing the game as quickly as possible.

TAS timing (power on until last input): 41340 frames, 13:46.469

RTA timing (press 1 to start the game until 🟢 snaps into place): 30186 frames, 10:03.479

! Model

The run is performed on the Sinclair ZX Spectrum +2A. 🔺🟢🟦 can sometimes encounter lag frames, reducing the game to half speed in these moments. 128K versions of the Spectrum run their Z80 processor at a slightly higher clock rate, and the +2A and +3 also have some improvements in memory access speeds. As a result, the game runs fastest on these models. The +3 is a disk-based system, and 🔺🟢🟦 has never been officially released on disk, so the run uses the +2A and loads the game from tape.

! General information

All characters move left or right at the same fixed speed. 🔺 can shoot and destroy enemies. 🟢 can jump. 🟦 is heavy and falls through collapsing floors.

In Level 1, we go 🟢🔺🟦🟢🔺🟢🔺🟢🟦🟢🔺🟢🟦🟢. In Level 2, we go 🟢🔺🟢🔺🟦🟢🔺. In Level 3, we go 🔺🟢🟦🟢🟦🟢🔺🟢🟦🟢🔺🟦🟢🔺🟢🟦🟢🔺🟢. In Level 4, we go 🟢. In Level 5, we go 🟢🔺🟦🟢. And with that we are 🔺🟢🟦.
