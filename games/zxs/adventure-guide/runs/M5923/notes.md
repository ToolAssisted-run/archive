''Adventure Guide'', also known as ''Demonstration Adventure'' and ''Introduction'', is a short text adventure game created by Tom D. Frost and published by Tartan Software as part of ''6 in 1'' and many other Tartan compilations for the ZX Spectrum. It was also bundled as a tutorial in the ''[https://www.ifwiki.org/Adventure_Builder_System|Adventure Builder System]'', also by Tom D. Frost. The goal is to find the large diamond hidden in a farm.

A complete solution can be accessed in the game by typing HELP. Another solution is available [https://www.the-tipshop.co.uk/cgi-bin/info.pl?name=Adventure%20Guide|here].

This run was made on the 128K model since it boots the fastest. I tested a run with the +2A model, but it didn't bring improved frames during input. The parsing system has a particular input delay time due to the ZX's beeper being used. You have to wait 3 frames for each press, 5 frames for each 2 presses, and 7 frames for each consecutive letter. I wanted to use shorter words for "cupboard" and "diamond" and tried them out, but shortcuts are not implemented for using items. Also, you can't carry an object while opening things, you have to drop them first.
