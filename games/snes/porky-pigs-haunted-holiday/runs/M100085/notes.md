!!__Game objectives__


* Emulator used: BizHawk 2.4.

* Aims for fastest time and avoids all lag frames possible

* Manipulates weather choice for less loading times

* Uses hardest difficulty

* Takes damage to save time

* Uses an unique glitch to skip 70% of the entire game


The new run saves 22 frames over the previous run thanks to a few small new optimizations, shorter loading times for almost all Level 6 room transitions, and extra lag reduction while taking advantage of the global timer which controls those chain swings and can’t be helped at all.

!!__About the demo glitch__

If you wait long enough at the title screen, a demo will start playing. This game has three demos:


* __Demo 1 - Level 1__ (Room 2 - The actual start of the journey - at least it was in the beginning of development of the game through one of early prototypes - after a straightforward simple room)

* __Demo 2 - Level 3__ (Room 1 - Atlantis raft - So long and a bit boring to progress. Next!)

* __Demo 3 - Level 5__ (Room 3 - Wackyland - Much better and it also skips an autoscroller section which is located one room before this destination)


During the loading transition of each demo, there are a few non-lag frames just before the demo fully loads. So, if you press start during this opportunity, the game will be paused instead of exiting the demo gameplay. Unpausing the game when the loading finishes allows you to actually control Porky in each demo. 

The required 3rd demo requires an absurd two minutes of waiting time because the game forces you to return to copyright screens rather than the title screen. In addition, if you want to play this game in Hard or Easy mode when you apply this peculiar glitch, here’s the thing: exiting a demo will reset the difficulty to Normal so for this run, access the Options screen after skipping the 1st and 2nd demos.


!!__Tricks, glitches and mechanics used during this run__


!__Slope technique__


The normal maximum speed when walking is 2, but during a slope the speed increments from the current speed until 4. Jumping off a slope keeps the maximum speed for some frames. However if you press the right button on the same frame you jump (if you're facing to the right), the technique can be extended a little further - it also applies to the left direction, with the difference you should press the left button instead.

I also discovered that ignoring the jump and pressing the aforementioned direction on the first frame Porky is going to start falling down, he will be one pixel further. Only useful for small slopes whose end points are short.


!__The camera mechanic__

You can move the camera while Porky is stationary: scrolling the camera (by holding X button + direction pad) moves faster than you, spawning enemies or objects earlier than usual. As soon as you stop doing it Porky's movement speed resets to 0 so the usage is very limited in this run.


!__Minimum speed loss__

If Porky is on the air, ignore pressing the left or right button for 4 frames so that the speed will reduce to 1, wait another frame so the speed returns to 2 and you can continue moving without problem. However if you wait a frame once again, repeat the same two steps then continue moving after returning to max normal speed because this time the normal speed loss will occur.

Also, there's an alternative setup: turn around for 2 frames, wait one frame and continue moving. The extra wait rule + avoid losing max normal speed also applies here.


!__Sprite glitch__

If you press left, right or down every other frame (a la Turbo mode) on bosses, they will not advance to the next sprite as normally intended until you stop pressing the buttons. The repetitive nature looks silly by abusing too much, but this glitch is funny + forcing the boss to not be animated = lag reduction when possible.


!__Moonwalk__

This trick only works if you are facing in the left direction and hold left + right buttons. Moonwalking looks like only a visual change at first, but there are a few benefits by clipping some small platforms if possible.


!__Weather system__

The weather effect is the highlight of this game every time you play again. This game chooses 'randomly' by delaying the title screen, skipping the title sequence or starting a new level on the map screen through different frames because the global timer decides the choice. 

Like the previous run as well as the 2025 any% TAS, getting normal weather is faster than having fog, snow or rain because they require more time to load the current room and the following ones when possible. In addition, they are prone to add some lag in the middle of some rooms.


!__Chain swing system__

Not noticeable when playing this game normally, but the way the chain swings behave… there's a situation: They are timed/controlled from the system rather than during the actual levels where you can find them. They own its global timer too!

The first real difference is shown when Porky reaches the unavoidable chain swing path from the 1-4 checkpoint: if you find small improvements they won't be enough unless you achieve further timesaves so you can avoid waiting time. 

However, because I skipped the first level, three more levels and 1/3 of the fifth level… the objective is only shown during the last level where in some rooms I sacrificed some time for lag reduction in order to keep the global timer advancing and once getting past the first of two chain swings from one of the bathroom sections, the rest you don’t need to worry after all.
