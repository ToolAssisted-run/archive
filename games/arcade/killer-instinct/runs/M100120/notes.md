**About the run:**
Killer Instinct for Arcade (L1.5D) featuring Sabrewulf on Hyper Speed beating all characters on Arcade Mode. Hyper Speed Mode a code you insert during each versus screen animations by holding right + QP + MP + FP (three punch buttons) at the same time with both controls Player 1 and Player 2 until the round starts in order to be archieved, the code speed up all in-game moves. 
- Played on Hardest Difficulty (5 - Extra Hard)
- No Combo Breakers used / No Hit Taken
- Character Showcase: Known combos & juggle glitches
