! Objective
* This run aims to see the potential of RNG manipulation in Digimon World 2. 
* There is no basis for comparison for this run as the team built is not viable in a normal speedrun. However, there is definitely still room for improvement, specially on better RNG on fights since I went for a "fast RNG seed" but not necessarily the fastest one.

! Category Rules
* Beat OverLord GAIA
* Timing starts on selection of "New Game" and ends at the "Win"-message after the last hit on OverLord GAIA.

! Strategy
* The main strategy was to use paralysis to make enemies miss without having to wait for the perfect RNG.
* Floor layouts were also manipulated for optimal traversing through domains which impacts not only the time spent but the need for digibeetle upgrades.
