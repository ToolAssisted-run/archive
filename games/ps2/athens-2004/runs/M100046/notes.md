To celebrate frame-accurate PS2 TASing finally becoming a reality (thanks eien!) I decided to do this silly thing that has been on my mind for a while now. I traded some speed for entertainment by naming the player "TAS", choosing Sweden as a country, and skipping the cutscene after the successful vault a bit later to have the "New W.R.!" prompt and a bit of the celebration afterwards. If you really wanted to optimize for speed you could cut all of those in exchange for maybe a second of timesave? Also going for not the EU/AUS ROM but the US or maybe the JPN ROM might save time as well, haven't checked

''Edit (Sep 3rd, 2026):'' Replaced movie file to sync on Chimera version x64-cf1e60bc.

!! Reproduction

To run this do the following:

## Download and extract Chimera version x64-cf1e60bc (https://github.com/ToolAssisted-run/chimera/releases/tag/nightly-2026-09-02)
## Have Athens 2004 (Europe, Australia) (En,Fr,De,Es,It,Pt).iso with MD5 Hash 9AC52F7F0AC7C458CD394193C2236826 available. (can, e.g., use https://emn178.github.io/online-tools/md5_checksum.html to check the hash)
## Open Chimera.exe
## Create a New Chimera Project with emulation core PCSX2, the game disc, and boot ROM ps2-0230e-20080220
## Download the movie file from this page.
## Go to File -> Open project.
## Select the M100046.chimeraproject file to open and play back
