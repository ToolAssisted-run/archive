This is a movie I made for fun, after I understood how the game generates shinies. Most of this analysis was probably done by other people, because there are a lot of tools out there, but I could never use them, so I did my own.

The RNG for Pokemon FR/LG is an LCG. It updates the seed using a formula x <- (a*x+c) mod m, where m is 2^32, the size of a 4-byte integer, common in computers. The parameters a and c are chosen so that all 2^32 values appear. The lower bits don't give very good randomness. For the values in the game, if a seed is odd, the next one is always even and vice-versa, so if you use it to implement coin flips depending on the remainder mod 2, for example, you always get heads-tails-heads-tails-heads-tails and so on, which is not random. Because of this, when the game gets a random number, it first updates the seed, then throws the lower 16 bits away, because the higher 16 bits are more random.

If you do a TAS, it's better to inspect the seeds by position. You can say seed 0 is at position 0, seed c is at position 1, seed a*(c+1) at position 2 and so on. You can use the lack of randomness in the lower bits to get the position of the seed really fast.

When generating Pokemon, the game does it different if it's wild encounter, or a pokemon you received by event.

When it's a wild encounter (I only looked a land), each route in FR/LG has 12 slots with distinct probabilities. Each slot has a pokemon species, a minimum and a maximum level. In a wild encounter, the game first rolls the RNG to get which slot it will use, then another roll to get the level. After this, it rolls the RNG again to choose one of the 25 different natures. In a pokemon, nature is determined by the personality value (PV or PID). Each time the game creates a PID, it rolls the RNG twice, first to get the lower 16 bits, then a second to get the higher 16 bits. After determining the nature, the game will keep generating PID's until it finds one that matches the nature it chose and use it for the Pokemon.

When it's a Pokemon you receive, it's much easier. The game just calls the RNG to get the PID and uses it.

Determining if a Pokemon is shiny uses your trainer ID and the Pokemon PID. There are two trainer IDs, the first is a public 16-bit number that's in your Trainer Card, the second one is a secret 16-bit number you can't see in normal gameplay. What the game does is: it XORs the public trainer ID, secret trainer ID, and the upper and lower parts of the Pokemon PID. If it gives a value less than 8, the Pokemon is shiny.

Because of the way things work, it's actually harder to get a shiny in the wild than to receive one. That's because if a seed gives a PID that matches a shiny pokemon for your trainer ID, since the PID also determines nature, it could be that this seed can never generate the PID of a wild pokemon, because of the process to choose nature first and then roll the RNG until a PID of a given nature.

Manipulating a shiny starter is pretty simple. When you finish naming the character, the game picks a value from a GBA timer register and sets it both as your public trainer id and the first seed of the RNG. Then, when you spawn in your room, the game rolls the RNG to set the 16 bits of the secret trainer ID, and finally when you close the "quite energetic" dialog, it generates the PID of the Pokemon. Because the timer register is 16-bit, there are only 65536 possible starting seeds for the RNG. In practice, it's very difficult to get all of them, since it's affected by how many cycles the program takes.

Using the PRET project, you can see the offsets of every function in the code, so I made a Lua script to log what's happening when the function is called. After playing really fast, at TAS pace I found that the game sets the initial seed/public TID, then generates the secret ID at a seed 871 units ahead, and then the pokemon PID at another 2727 units ahead. With this, it's easy to bot to find shinies. Say you have a given public trainer ID and want to wait 10 frames. Because the game advances the RNG mostly once every frame, you generate the starter at 10 units ahead of the last seed. You have 11 frames to choose your secret ID. If you can find a shiny one in them, you're good. Sometimes the game lags and won't roll the RNG in a frame, messing up the timing, but in all cases I could fix manually. After running this for all seeds I could get waiting at the naming screen, I found a solution wasting only 44 frames.

It's possible that there are more initial RNG seeds, though, because they are obtained from a timer, so you could press buttons in the intro and mess up the flow order and change the timing. I challenge the community to use this and improve the run! The timing I give is different from the movie length because I am counting up to the closing of "quite energetic" dialog, which happens at frame 5423.

There's also the Lua script with the search bot. It also has a hook for logging wild pokemon encounters that you can use to find shiny seeds in wild encounters. Most of the time, the frames are very far away, but you can use Teachy TV static screen to advance the RNG a lot to wait less time.
