This kickboxing game is amazing! Despite being a speedrun, this shows off a lot of the game's options when using a character with all the game's depth.

B punch
A kick
L dodge 
R power up to chain combos

The character from Croatia has 100% combo and can combo into the super, which skips a third round if used in the end of the second round. Counter hits cause more damage but this is not an easy game to manipulate the enemy, so I managed to show a few different to setups to kill including CH super and super when breaking the enemy guard. Taking damage would only save time if I didn't manage to finish the second round with a super. The yellow ending screen appears when doing a perfect or a super finish, but i need to do supers in order to skip round 3.

I'm not knowledgeable into the other characters but the speedrun uses the same character.

Enjoy!
