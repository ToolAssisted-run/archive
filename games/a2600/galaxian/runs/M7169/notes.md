!! Objectives

* Emulator used: BizHawk 2.11 (Stella core)
* Beats 20 levels (fastest speed)
* Aims for fastest time

!! Comments

Pretty self-explanatory run. 20 waves of aliens are cleared in the fastest possible time, on the Atari 2600 version of Galaxian.

The initial version was a quick solo run by me. eien86 and nymx have improved this, so they are co-authors. The new version contains a "double-kill" trick, as shown in the forum, and clears 20 waves instead of just 1.

There is also a kill screen causing the game to crash once 136 lives are reached, which this run does not reach.

!! Possible improvements

Maybe luck could be manipulated to make the aliens fly down more, but this is a very simple and old game, so I'm not sure.
