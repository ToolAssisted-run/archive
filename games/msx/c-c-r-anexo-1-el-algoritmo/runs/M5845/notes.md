''C.C.R.: Anexo 1 - El Algoritmo'' (''C.C.R.: Annex 1 - The Algorithm'' in English) is a graphic adventure game for the MSX made by José Soto Gándara. The game was a submission for MSXdev'18, with an English translation by Daniel González following soon after its release. This run plays through the original Spanish version. You can get the game [https://www.msxdev.org/2018/06/27/msxdev18-4th-entry-c-c-r-anexo-1-el-algoritmo/|here] ([https://web.archive.org/web/20181031081115/http://www.msxdev.org:80/2018/06/27/msxdev18-4th-entry-c-c-r-anexo-1-el-algoritmo/|archived link]).

The game's plot involves a programmer being chased by government agents seeking the mysterious algorithm in his possession. The opening scene, where he is about to jump off the building he works at, is told ''in medias res'' and the rest of the game is a flashback to the events leading to that scene.

Effort was spent optimizing each Spacebar press, and 18 frames are spent between each choice. The game has an abrupt ending that doesn't really resolve anything, it just leads to a splash screen.
