!!!Sammy Lightfoot - Score Attack/Maximum Score
*For more info on the game itself, see [8220S]
*As copy/paste of the input for the final level syncs each time it loops, I figured it would be an easy task to create a max score run.  
*Score is only obtained based on how quickly the levels are completed with the maximum possible displayed score being 999990 points.

!What, no encode???
*Um...you probably don't want to watch this entire thing anyway.
*Everything after the first iteration of Level 7 is identical to the first Level 7 iteration. So once you've seen up through that level, you've seen it all.
*Everything up to the end of the first iteration of Level 7 is identical to the any% run listed above...so if you've watched that, there's nothing new here other than a whole lot more of the same and the changes to the score counter.

!But how to end???
*Unfortunately, I'm still not exactly sure where the ideal place to end this run is. So I've created 4 different versions:%%%
**{{Score Attack}}1) A run that rolls over the score counter as fast as possible then immediately stops inputs even though the loop is not finished (this submission).%%%
**{{Max Score}}2) A run that delays finishing a stage to yield the score counter displaying its maximum possible then ending input immediately. ([UserFiles/Info/638173539408226376|This Run])%%%
**{{Score Attack}}3) A run that rolls over the score counter as fast as possible then continues to complete the loop. ([UserFiles/Info/638173539835299852|This Run])%%%
**{{Max Score}}4) A run that delays finishing multiple stages in order to complete the loop while still yielding a score counter displaying its maximum possible after that loop. ([UserFiles/Info/638173539600783634|This Run])
**These are listed in order of duration.

*I'm guessing we probably don't want runs that don't complete the loop (meaning options 1 and 2 are probably not ideal), but I've included them here just in case.  I'll let the judge decide which option would be ideal and whether the branch should be "Score Attack" due to roll-over, or "Max Score" if one of the max display options is chosen.
