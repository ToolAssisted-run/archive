!!!Arcade Baseball (Compute's Gazette)
Here's a computerized version of the once-popular mechanical baseball game found in the preelectronic arcades. The only difference is you don't need any dimes or quarters to play.

The article for this game can be found on page 38 of [https://archive.org/details/1986-05-computegazette/page/n39/mode/2up|Compute's Gazette Issue 35 (May 1986)]

!!Why TAS This Game?
The continuation of TASing games from my all-time favorite magazine, Compute's Gazette. This makes my 107th TAS from this series. 

Never played this game, because I was more interested in "Vampyre Hunter", found elsehwere in this same issue, because it was a "Text Adventure" game with graphics. Well, I was never able to get the thing to run...even with the following issues and their corrections. This was the type of game that I liked a lot back then, as it was like reading a book...only you get to control the action.

As for Arcade Baseball, I think I missed out on some experiences. This was a really neat game and had some very senstive controls in trying to accomplish a hit. So the game was highly variable and also highly replayable.

!!Game Difficulty and Ending
There is no difficulty selection. As for the ending, it is clearly stated when it shows "GAME OVER". 

!!Effort In TASing (Not BOTed)
Here, I score once and let the game coast out to the end. In this version, the game doesn't respond with an inning from the computer. So the "HOME" that you see is when a two player game is performed.
