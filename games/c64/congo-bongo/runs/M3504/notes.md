!!!Congo Bongo for Commodore 64

This submission is a run using identical path routing to the [3452M|currently published run] which was completed using PAL settings in BizHawk.

This submission uses NTSC settings.  The only noticeable difference is slightly faster game and music tempo with the NTSC settings.

I could not determine which version this cartridge dump is, but there are no obvious graphical or sound glitches with either setting.  It may be a universal release.

As such, with only minor tweaking of input, the path routing could be replicated under NTSC settings resulting in a faster game by about 3.2 seconds.

It's not by much, but it is the faster of the two runs.  I feel it should replace the current publication.
