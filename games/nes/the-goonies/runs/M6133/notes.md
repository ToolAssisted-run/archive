Well, this is Goonies, but not Goonies II this time xD. Anyway, this movie of The Goonies aims at getting all items and clearing all stages.

!!! The Goonies "all items" in 04:14.43

!! Run details
*Emulator used: FCEUX 2.2.3
*Takes damage to save time
*Uses death to save time
*Beats all stages
*Gets all items

!! Run summary
*This run tries to get all 8 inventory items in the game, which are headphones, waterproof, helmet, coat, bomb, bag, armor, jumping shoes and slingshot. Each item needs a specific input on its secret area for it to appear, except for slingshot that is obtained from bombing a door.
*Most of Any% tricks are ported here. Pretty much same scenario but I made use of the pause glitch that skips doors. It is now even more useful in Stage 4 as it prevents dying from the rocks that fall periodically.
*This run doesn't get diamonds. It also doesn't get any Konami bonuses :(
*Setting up the death boost in Stage 3 was a bit harder because we travel more than Any%
*In each stage, the distribution of the goonies is decided right at the start of the stage, depending on which frame you enter at. So to get the right door for fast goonies grab, I may wait few frames (usually 1 or 2 frames) before I enter the stage.

!! Stage comments
! Stage 1
*Same as Any%. The glitch that grabs the goonie close to the end is very helpful, Also, we get the headphones, but most importantly, unlike Any%, I tried to be careful with my movement so I don't get damaged randomly for the death boost in Stage 3.

! Stage 2
*Here, I wasn't intending to get the slingshot but due to manipulation for the goonie, I somehow got it and I immediately thought it would be useful. It actually was better than kicking! Also, it was next to the coat which makes it even better. Still trying to manage health here.

! Stage 3
*All TASers for this game pointed out that you need to get the timer of the ghost to reach 0 so it appears. The time is managed by the address $011C. Before entering the room of the death boost, it is better to have that time as close to 0 as possible, as the values of that address change every frame. I found out that shooting enemies make this value change significantly. I managed to get it at 4 by shooting the yellow mouse on the blue room (that has the helmet).
*Getting the bomb after the death looks suboptimal, but probably it is the only option as doing any extra manipulation earlier will cost a lot more.

! Stage 4
*I liked the usage of pause glitch, it significantly made the stage a lot more smoother. This stages gives us bomb bag but at this point, we need to carry just one bomb at a time!

! Stage 5
*The final stage! Well, I think it is pretty straight forward. We get waterproof and the armor. I guess waterproof save us some time here as it protects from the waterfall. After this stage we proceed to ending. Note that we need to have 5 goonies rescued before finishing.
