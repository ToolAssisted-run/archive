!! Run comments
This appears to be the first TAS of the U-version to get the best ending, but there have been a few real-time speedruns in this category. This TAS follows the real-time route with a few tweaks, such as which mighty coins to collect and there are also many room solutions that can be played slightly differently in a TAS setting.

There are a lot of different options when it comes to the routing. For more information about some of the considerations that have gone into it, the interested reader is referred to the resources linked to above.
