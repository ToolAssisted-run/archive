Cybercoaster by Clockwork Cats is a fun little homebrew NES game that is reminiscent of certain parts of Lawnmower Man on SNES. 

There are six levels in full with each stage having three laps.  There are little pink balls that can be acquired but they do not serve any purpose other than as collectibles and visual markers of where to go.  Some of the balls are not gotten in later stages if they would cause time loss.  The A button is used to accelerate up to a certain max speed and B button is used to brake.  Start is used to begin the game, and to move to next stage once stage is completed.  There may be only a single frame upon stage completion showing "Finish" before start is pressed going to the next stage.  

There is a visual speed indicator on the upper right once the gauge is full. However, there is a little bit more speed that can be achieved if the A button is held a little while longer.
