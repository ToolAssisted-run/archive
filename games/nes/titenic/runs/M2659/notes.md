!! Comments

! Glitches NOT used in this run

;Game end glitch:The game can be beaten in 48 frames by pressing Start on the second controller after the first Level finished loading.

;Boss clone glitch:Characters from the game can be cloned by pressing A then B on the second controller, the outcome can be manipulated by pressing left or right on the second controller. The last boss could be cloned in the beginning, fall into the water and die.

;Boss skip glitch:By pressing Start on the second controller in a boss room after the room finished loading will skip the boss fight.

! Glitches and Tricks used in this run

;Camera speed:The camera has a fixed speed it can scroll, so it looks like the game is an autoscroller, but it isn't.

;Jumping in mid-air:While in mid-air it is possible to jump by pressing down, two frames later A. However it is only possible to jump straight up. Moving forward will cause the glitch not to work.

;Stuck in mid-air:In mid-air press down, down, down+A and the character will get stuck.

;Second player spawn:By pressing A then B and manipulate it with left or right a second playable character will spawn. It could be the same as the first player, both are controlled with one controller, but direction needs to be inputted on both, else the characters will move very slow. To seperate characters can be controlled individually. The downside of this is that the room where the characters are spawned will never scroll left. In boss room the effect will be carried over to the next level and soft locks the game.

;Room load stop:Pressing Start on the second controller while the room load will stop the loading and the room will have a different graphic pallette.

;Qicker exiting:By pressing select before exiting a room the next room will load quicker.

;Luck manipulation:The randomness depends on the B presses, I manipulated some enemies not to attack, or in case of two bosses to run faster.
