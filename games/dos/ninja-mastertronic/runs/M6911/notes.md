!! Introduction

Here's the end of my (until now unaware) quest to become the TASer with the most Ninja-based game publications. See [10058S] and [10061S] for an in-depth explanation of the generalities of this game.

The DOS version is similar to the C64 in that the positioning of the idols and the enemies can be manipulated by starting the game later. This version doesn't have a known out of bounds glitch, so the routing needs to be one that traverses the game "normally".

Luckily for me, the very first frame you can start this game in already gives a "perfect" route, with only 9 room traversals to all idols, including Akuma's Chamber. Nothing special otherwise; I just anihilate all my enemies to a puddle of human remains.

In this version, you don't win if you die when coming back, so I swifly make my return to the Torii gates to beat the game.
