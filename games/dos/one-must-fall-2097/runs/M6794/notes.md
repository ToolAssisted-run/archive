!! Introduction

One Must Fall 2097 is the best fighting game ever created. Period.

In this movie I beat the single player mode in the hardest difficulty. Details:

* Sets speed to an enjoyable setting. Anything faster is way too fast.
* Hyper Mode (more combos and enhanced moves)
* Single Round fights
* Uses in-game code to enable the hardest difficulty.  First, set it to "Deadly" by pressing right until it changes.  Second, set it to "Ultimate" by reaching "Deadly" and then pressing "OMF"
* I use Raven because I'm an edgy boy.
* Uses in-game code to re-distribute Raven's stats to have max power, better agility, and zero endurance (I won't get hit anyway). I do this by going through all the fighters and using the kick button while I change the stats.
* I fight with Katana because I am super edgy and change it's color (by using a code) to all black because I am mega edgy.
* I end all fights except for Major Kreissack with the destruction move (entertainment/speed tradeoff but also maxes score)
* I fight optional fighters Fire and Ice too (entertainment/speed tradeoff but also maxes score)
