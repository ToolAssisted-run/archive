!! Introduction

Kings of the Beach is an early DOS sports game I used to play with my brother. We discovered that, if you jump+block when the other player is serving, you can do a mega fast serve that bugs out the game. This is a very useful trick for the first matches, until the AI gets smart and gets to return the ball. Those late matches look more normal, with me manipulating things as much as I can to end each point as fast as possible.
