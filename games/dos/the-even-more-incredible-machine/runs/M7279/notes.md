!! Introduction

[https://en.wikipedia.org/w/index.php?title=The_Even_More_Incredible_Machine&redirect=yes|The Even More! Incredible Machine] is an extension to __The Incredible Machine__ which contains all original 87 puzzles (now skippable), plus 73 additional ones, including new exclusive objects.

The player is tasked with solving challenges using a given set of [https://en.wikipedia.org/wiki/Rube_Goldberg_machine|Rube Goldberg machine] components.  

In this movie we solve all 160 puzzles as fast as possible.  I (DrD2k9) used [10031S|eien86's original submission] as a baseline and made improvements from there.

TASing this game is really demanding, as every puzzle requires a different approach, instead of, say, a platformer, which has its own challenges but is overall not so taxing in problem solving. While the  developers got smart in this sequel and tried to force much less opportunity for skips or unorthodox solutions, we still found plenty.

Enjoy!

!! Redo Notes
! Improvements in this submission over the original come from three primary aspects.
* Different (newer) emulated computer settings allow for smoother emulation of the game.
* Mouse movement optimization.
* Faster puzzle solutions.

! Basic improvement approach applied to each individual puzzle:
# Optimize mouse movements using original puzzle solution.
# Test new possible solutions and compare to original.
# Implement new possible solution if faster.

In total, 133 ish of the 160 puzzles were improved.  These improvements range from minor part repositioning all the way to completely different solutions.

The improvements result in a savings of 119,430 frames over the original submission.  The new movie length is 79,547 frames, meaning we saved more frames than the resulting movie ended up being in duration.
