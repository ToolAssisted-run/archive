Run Run is a very simple autorunner flash game of the "Squirrel Family" series by Mateusz Skutnik.

I did this run basically to test out the ruffle core in Chimera.

I played this game in my childhood from "Champak Jogo Disk", which a CD that comes attached with an Indian magazine that was partnered with Brazilian publisher Digerati. While trivial to TAS, the game is brutal to play casually. I've literally never seen the ending until I did this run.
