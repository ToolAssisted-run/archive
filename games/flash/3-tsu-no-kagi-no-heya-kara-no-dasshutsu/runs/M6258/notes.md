3つの鍵の部屋からの脱出 by YominoKagura

__Routing:__

*We head over to the lower left cabinet and use the the color combination code: R, Y, G, G, Y, R
*We are forced to pick up the handle first before the triangle key which we need for the pliers
*Head over to the blue checkered box to use the triangle key and get the pliers
*Use the pliers for the top half of the compartment and go to the white safe (Code: 156)
*We obtain a red key that is needed to unlock our access to the combination lock that opens the door
*Go to the combination lock and use the code "739" and then leave
