3つの絵の部屋からの脱出3 by YominoKagura

Well, would you look at that! I finally got my font situation fixed! This room also has the gimmick "collect-the-shapes" to get the key.

__Routing:__

*Code to get the Room's card via "Three Circles": small star, small star, diamond. We need this card to obtain the blue square.
*Color code for first frame: G, Y, B and open the frame to get the red circle
*Insert the card for the second frame and use the code 952, get the blue square
*Final frame colored number code: 425 and get the yellow triangle
*Head to the blue checkered box and use all your shapes. Open the box, get the key and leave.
