!Introduction:
*"Prince of Persia: Special Edition" is an Adobe Flash game created by Ubisoft that was meant as a promotional game for the upcoming 3D title from the time "Prince of Persia: The Sands of Time". This game only contains one level with a boss fight (Jaffar). The physics and visuals of this game are practically the same as the [https://youtu.be/ywf1h0_bT60|MacOS/Macintosh] version. Basically, really slow and awkward.

!Objectives:
*Beat the game as fast as possible without the [https://youtu.be/Tt33Sl-Bkho|menu exploit]. 
*Small glitch included
*Obliterate Jaffar

!Routing:
*Well, finding any speedruns of this game were scarce. Also, from the PoP speedrunning community. Eventually, I came across maybe one good speedrun that didn't use the menu exploit which was a [https://youtu.be/dWFWwx3DIWo|2:05 IGT]. However, this run didn't use the same route as the runner went around the gate room. So, I made a base TAS without testing other techniques so that I had a slightly better run to compare the techniques with. I'll show screenshots of a Google Doc I made for this.

!Gate Clip:
*While the transition of the gate is moving down, the prince can still make it through the gate with a long jump.
