"3つの絵の部屋からの脱出5" is part of Yominokagura's "Room's room" escape room series. 

__Quick Intro:__

I originally had planned to TAS all of Yominokagura's escape rooms until I realized that there were many visual errors with the numbered and colored combination locks that were unavoidable and needed to escape the rooms. However, the visual errors only occurred when I was pairing libTAS with Ruffle. The visual errors didn't occur when using Ruffle demo or the exact same Ruffle nightly build I'm using for this submission. __Edit:__ The issue has been solved, future tases will include the font. 

__Routing:__ Thankfully, we can bypass everything and immediately get to the key:

*Right
*Picture frame with upside down "A" combination: L, R, R, L, R, L, R
*Frame falls off revealing the key
*Go back, Left, select key
*Click on the door twice (one to unlock it, the second is to open it)
* Enjoy your lowercase "clear"
